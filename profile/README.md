## English Introduction

**rednote-infra** is the open-source GitHub organization of the Server & IDC Infrastructure team at Xiaohongshu (REDnote). We focus on server infrastructure management, IDC operations automation, and hardware-layer platform tooling.

Our goal is to open-source the IaaS engineering practices we have developed internally, helping the broader community reduce redundant infrastructure engineering efforts.

### Open Source Projects

| Project | Language | Description |
| --- | --- | --- |
| [redfish-python-sdk](https://github.com/rednote-infra/redfish-python-sdk) | Python | A Python SDK built on the DMTF Redfish standard for server out-of-band management (BMC automation), supporting power management, hardware inventory, firmware upgrades, and more. |

## 中文介绍

**rednote-infra** 是小红书（REDnote）中台技术部服务器 & IDC 组在 GitHub 上的开源组织。我们专注于服务器基础设施管理、IDC 数据中心运维自动化及硬件层平台工具的开发与开放。

我们的目标是将内部沉淀的 IaaS 层工程实践以开源形式回馈社区，降低行业内基础设施工程的重复建设成本。
