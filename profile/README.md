## About Us

**rednote-infra** is the open-source GitHub organization of the Server & IDC Infrastructure team at Xiaohongshu (REDnote). We focus on server infrastructure management, IDC operations automation, and hardware-layer platform tooling.

Our goal is to open-source the IaaS engineering practices we have developed internally, helping the broader community reduce redundant infrastructure engineering efforts.
